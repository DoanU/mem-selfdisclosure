# Memory, Self-disclosure, and Depression
This repository contains the full analysis script written in R for the following journal article:  

Doan, U., Hong, D., & Hitchcock, C. (2025). Please, just talk to me: self-disclosure mediates the effect of autobiographical memory specificity on adolescent self-harm and depressive symptoms in a UK population-based study. *Journal of Affective Disorders, 376*, 10-17. <https://doi.org/10.1016/j.jad.2025.01.141>

**Pre-registration**: The research questions, hypotheses, and analysis plan were preregistered on OSF, at https://osf.io/5xdns.

**Data access**: Data used in this study comes from an existing UK population-based study, the Avon Longitudinal Study of Parents and Children (ALSPAC). For more infomation on this dataset, please visit http://www.bristol.ac.uk/alspac/.

**Analysis**: The .rmd file in the `analysis` folder include details of all necessary packages, and the full analysis pipeline for all results reported in the above paper including primary, exploratory, and sensitivity analysis. Missing data were handled using multiple imputations.
